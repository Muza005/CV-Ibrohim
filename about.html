About Ibrohim Sirojiddinov

I'm a backend-focused Node.js developer with over a year of hands-on experience building and maintaining server-side applications, RESTful APIs and database-driven systems. Since July 2025 I've been a Backend Developer at Telecom Soft in Tashkent, working on backend systems built around ISP business and commercial processes.

I work independently: I research solutions, ask the right questions and deliver backend tasks end to end with Node.js, Express.js, Fastify, PostgreSQL and Redis. Improving existing backend workflows and application performance has contributed to efficiency gains of approximately 15%.

I care about architecture that stays maintainable as it grows: clear application layers, API security, authentication and careful database modeling. I document APIs with Swagger/OpenAPI and use spec-driven design to capture system requirements and development workflows before the code is written.

I'm also expanding my practical knowledge of AI agents and agentic AI, and how they fit into software development, automation, documentation and modern engineering workflows.

How a request flows through my backends

The layers I design into every API, from the edge of the network down to the database.

    Calls a versioned, documented REST API.
